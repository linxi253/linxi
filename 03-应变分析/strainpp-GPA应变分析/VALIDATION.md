## 验收范围

本次验收覆盖 GPA 数学实现、相位处理、FFT 坐标、G 向量约束、各向异性像素、
坐标旋转、可靠性掩膜、TIFF/DM3/DM4 读取、命令行、GUI 后台任务、结果导出、
Python 安装包和 Windows 可执行文件。

自动化测试包含：

- 奇数和偶数尺寸 FFT 往返；
- 跨 `-π/π` 相位边界的导数及位移连续性；
- 已知仿射位移场的完整应变、旋转和位移恢复；
- 旋转坐标系与各向异性像素标定；
- 共线、越界、接近直流分量等无效 G 向量；
- Bragg 峰检测及数值噪声底抑制；
- 低幅值和相位残差区域的可靠性掩膜；
- RGB、TIFF 堆栈和 DM 标定读取；
- GUI 构造、发布包导入及打包后科学计算冒烟测试。

## 推荐起始参数

1024×1024 原始图底部含有比例尺和文字。建议先在内存中裁掉底部，再进行
FFT 和选峰：

```powershell
strainpp-gpa "D:\data\20260713\0080 HAADFgrey.tif" `
  --crop 0 0 1024 920 `
  --pixel-size 0.025252525 `
  --g1 96 27 --g2 96 -15 --sigma1 6.5 --sigma2 6.5 `
  --output "E:\your-output-directory"
```

其中 `0.025252525 nm/px` 是根据图中 5 nm 比例尺约 198 px 推算的值，并非
文件元数据。用于发表或绝对长度测量前，必须用显微镜采集记录重新核对。
2048×2048 滤波图若确为严格 2 倍插值，其对应起始值约为
`0.012626263 nm/px`，也需要独立确认。

上述两个 G 向量是在裁剪图上的稳健起始选择，不代表唯一正确的晶体学选择。
不要把一对中心反演峰（例如 `(-96,-27)` 与 `(96,27)`）同时作为 G1/G2，
因为它们共线，不能恢复二维位移梯度。高斯宽度可从 6.5 px 起步，并通过
改变宽度后结果是否稳定来检验。

## 实际运行结果

在不改写源文件的前提下，对 1024×920 裁剪图使用上述参数完成了全量计算：

- G 矩阵条件数约 4.13；
- 可靠像素约 97.8%；
- 有效像素中绝对应变超过 50% 的比例约 0.07%；
- 完整计算约 0.7 秒（本次验收机器）。

2048×1840 滤波裁剪图的无位移快速验收中，可靠像素约 98.0%，计算约
1.3 秒。时间只用于说明测试规模，不是性能保证。

极少量超大应变可能来自缺陷、相位奇点、边界或选峰/掩膜参数，而不是程序
崩溃。软件会保留为浮点值、标记无效区为 NaN，并报告极端值比例；解释前应
结合质量掩膜和原图检查。

## 仍需实验人员决定的事项

- 物理像素尺寸：必须以采集元数据或可靠标定为准；
- 无应变参考区：本次没有替用户假设材料中哪一块物理上无应变；
- G 向量对应的晶面族及最终高斯宽度；
- 结果是否满足具体材料、显微镜和发表流程的误差要求；
- Windows EXE 正式发布签名：构建脚本已支持证书，但仓库不包含私钥证书。

这些属于实验输入或发布凭据，不能由程序从图像本身可靠推断。
