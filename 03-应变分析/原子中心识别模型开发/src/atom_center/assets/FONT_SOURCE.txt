Audit 56 correction: this repository does NOT ship the font file. The .otf is
an optional local asset: to enable it, download the upstream file above, verify
its SHA-256, and place it next to this file under the name
NotoSansCJKsc-AtomAnnotator.otf. Without the asset the annotator falls back to
system fonts (Tk defaults plus the platform CJK fallbacks already configured in
the GUI), so Chinese task names, file paths, and metadata remain readable on
standard Windows installations; the bundled font only guarantees consistent
rendering on systems lacking an optional CJK font pack.
