# 第二阶段：数据采集与原子中心标注

## 1. 本阶段交付标准

第二阶段先建立可审计的真实实验数据集，不急于追求“大数据量”。HAADF-STEM 与 HRTEM 必须建立两个独立项目；两者可以共享标注工具和坐标规范，但不能混成同一个模型的数据。

数据量同时用三种口径报告：

1. **独立视野数**：一次移动到新区域后获得的原始视野；
2. **独立采集批次数**：同一连续采集、同一序列或高度相关的相邻区域归为一个 `acquisition_id`；
3. **已审核原子中心数**：完整标注区域内的点数。

切成 100 个小块、旋转增强 10 次或从同一电影取 100 帧，都不会变成 100 个独立采集样本。数据划分必须先按 `acquisition_id` 分组，再裁剪和增强。

## 2. 建议的原始目录

```text
data/raw/
├── haadf_stem/
│   └── <sample_id>/
│       └── <acquisition_id>/
│           └── *.tif
└── hrtem/
    └── <sample_id>/
        └── <acquisition_id>/
            └── *.tif
```

工具会从这两层目录名自动推断 `sample_id` 和 `acquisition_id`。原图应为未压缩或无损的 16/32 位 TIFF；不要用截图、JPEG、伪彩色图、傅里叶滤波图或已经增强的图代替原图。若显微镜原始格式为 DM3/DM4，保留原文件归档，同时无损导出 TIFF 和采集参数。

同一时间序列、焦距序列、连续扫描序列及其裁剪必须使用同一个 `acquisition_id`，以防训练集和测试集泄漏。

## 3. 应覆盖哪些变化

### HAADF-STEM

- 不同材料、晶带轴、晶格旋转和像素采样；
- 不同厚度、剂量、信噪比、漂移和扫描畸变；
- 体相、界面、晶界、边缘、缺陷、空位以及污染区域；
- 不同显微镜/探测器，以及内外收集角；
- 强弱原子柱同时存在、背景强度突然变化的困难区域。

### HRTEM

- 不同材料、晶带轴、厚度与像素采样；
- 正/负离焦、球差、像差与相位对比反转；
- 明原子、暗原子及混合对比；
- 不同剂量和信噪比、非晶背景、边缘、界面与缺陷；
- 同一结构在不同离焦条件下的配对图像，条件允许时配套多层切片模拟。

HRTEM 中强度极值不一定等于投影原子柱位置。标签语义必须始终是“投影原子柱中心”，不能一部分图标亮峰、另一部分图标暗峰。如果某个区域仅凭实验图无法可靠判断，就缩小完整标注 ROI 排除该区域，或在后续加入成像模拟后再标；不要猜测。

## 4. 需要多少数据

下面是针对“本实验室若干材料/条件的专用模型”的工程起点，不是普适定律，也不把增强图计入样本数。

| 里程碑 | HAADF-STEM | HRTEM | 采集批次要求 | 目的 |
|---|---:|---:|---:|---|
| 流程校准 | 10–15 个独立视野、约 2,000–5,000 点 | 15–20 个独立视野、约 3,000–8,000 点 | 至少 3 个 | 验证标注规范与训练链路，不作为最终精度结论 |
| 第一版基线 | 30–50 个视野、60–120 个完整 ROI、约 5,000–20,000 点 | 50–80 个视野、100–200 个完整 ROI、约 8,000–30,000 点 | 至少 5 个 | 训练初始模型并找失败类型 |
| 可用 v1 目标 | 80–150 个视野、200–400 个完整 ROI、约 30,000–100,000 点 | 120–250 个视野、300–700 个完整 ROI、约 50,000–150,000 点 | 分别至少 10/12 个 | 建立按批次隔离的训练、验证和盲测集 |

一个完整 ROI 建议覆盖至少约 `10 × 10` 个晶胞，并包含足够背景；常用边长可在 256–640 像素之间。整张图能够全部确认时可直接标整图，否则只框选确实会全部标完的非重叠 ROI。

如果模型只服务于一种材料、同一台显微镜和窄参数范围，第一版基线可能已经够用；每增加一种明显不同的材料、像素尺度、显微镜或 HRTEM 对比域，建议再加入至少 20–30 个独立视野。已有研究证明，针对单一结构的网络可以从约 30 张 `256 × 256` 实验图起步，但也显示常规方法常使用约 2,000 对图像或数百个模拟结构；这说明“30 张”只能作为窄域起点，不能当作通用模型保证。[Chen et al., Scientific Reports (2023)](https://www.nature.com/articles/s41598-023-29606-9)

模型在训练分布外的界面和背景突变区域可能明显失效，因此困难场景的覆盖比重复标更多完美晶格更重要。[Wei et al., atom-segmentation benchmark](https://arxiv.org/abs/2207.10173)

### 何时停止继续标注

不要只看总点数。分别用 25%、50%、100% 的训练数据画学习曲线，并始终在完全未见的 `acquisition_id` 上评测：

- 点匹配 precision、recall、F1；
- 定位 RMSE/95 分位误差（像素及 pm）；
- 按材料、像素尺寸、SNR、缺陷、界面、对比极性分层后的最差结果；
- 将预测点送入 PPA 后，无应变参考区的应变噪声。

当连续两轮增加数据后整体 F1 提升不足约 0.5 个百分点、定位 RMSE 改善不足约 0.02 px，并且最差场景也达到项目验收线，才可以认为当前适用域暂时饱和。否则应优先标注模型失败的图，而不是随机重复添加容易的完美晶格。

## 5. 标注工具使用方法

双击以下任一文件：

- `scripts/annotate_haadf_stem.cmd`
- `scripts/annotate_hrtem.cmd`

或在 PowerShell 中运行：

```powershell
.\scripts\start_annotation.ps1 -Modality haadf_stem
.\scripts\start_annotation.ps1 -Modality hrtem
```

操作顺序：

1. 如果知道采集信息，可以填写并批量复制到同文件夹的未审核帧；不知道可留空。
2. 选择“整图已完整标注”，或框选一个/多个互不重叠的完整标注区域。
3. 在区域内左键添加点，拖拽微调，右键删除；滚轮缩放，工具栏平移。
4. 必须标出范围内每一个目标原子柱；中心在 ROI 内即标，范围外不标。
5. `Ctrl+S` 保存草稿；`Ctrl+Enter` 审核通过并进入下一帧。

显示分位数和“反相显示”只影响界面，不修改原图或坐标。任何点位、ROI、直径或元数据变更都会把“已审核”自动退回“草稿”，并在约 0.7 秒后原子化保存。

建议记录字段（全部可留空，不会阻止审核或导出）：

- 共用：`sample_id`、`acquisition_id`、像素尺寸、加速电压；
- HAADF-STEM：探测器内/外收集角；
- HRTEM：离焦、球差和对比极性。

若 `sample_id` 或 `acquisition_id` 为空，导出器会为当前任务生成稳定的
`auto-sample-*` / `auto-acquisition-*` 分组标识，并在 CSV 中标记
`group_id_source=project_fallback`。这样可以继续标注和训练准备，同时把未知来源
保守地留在同一分组中。负责人在正式划分数据集前仍应尽量补充真实采集批次；
标注人员不得猜测或编造参数。

原始标签 JSON 位于 `data/labels/<modality>/`，精确浮点 `(x, y)` 是唯一真值；CSV 清单位于 `data/manifests/`。YOLO 小框不是原始标签，只能由工具派生。

## 6. 审核和质控

- 每批先共同标 3–5 张图，确认“什么算一个原子柱”和边界规则；
- 随机抽取 5%–10% 由第二个人盲标，统计一对一匹配后的标注者间误差；
- 建议标注者间中位误差控制在 0.2 px 内，95 分位控制在 0.5 px 内；达不到时先修订规范；
- 不确定区域应排除，不要把猜测伪装成真值；
- 盲测集至少保留两个完全未参与训练的采集批次，模型选择期间不得反复查看并据此改参数；
- 模拟数据可以扩充成像条件，但最终盲测必须由真实实验图组成。

AtomAI 等显微图像框架同样把网络输出定义为原子种类/位置并允许后续精修，这与本项目“检测候选点 + 亚像素精修”的接口一致。[AtomAI, Nature Machine Intelligence (2022)](https://www.nature.com/articles/s42256-022-00555-8)

## 7. 派生导出

界面中的“导出已审核 YOLO”只导出已审核 ROI，并创建一个新的时间戳目录：

```text
<export>/
├── images/              # ROI 百分位归一化后的 8 位 PNG
├── labels/              # 由精确点派生的 YOLO 小框
├── source_map.csv       # 回溯原图、帧、ROI 与 acquisition_id
└── export_manifest.json # 坐标变换和导出参数
```

这个目录尚未划分训练/验证/测试，不能直接把同一目录同时当作训练集和验证集。第三阶段会先按 `acquisition_id` 分组，再生成正式数据集。
