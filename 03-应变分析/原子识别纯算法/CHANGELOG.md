# 版本记录

## v1.3

数据完整性与溯源（对应深度审查报告 P0/P1 项）：

- 逐帧强度参数溯源：新增 `frame_intensity_params` 逐帧快照，识别/重算/手动增删/重新关联都会记录当帧实际使用的孔径参数；CSV 每行新增"本帧强度参数"指纹列，`.metadata.json` 新增 `per_frame_intensity_params` 与 `intensity_params_consistent_across_frames`，部分重算后参数不一致不再被全局参数声明掩盖。
- 新增邻居污染 QC：每原子输出同帧最近邻距离与"邻居污染"标志（最近邻距离 < 孔径半径 + 背景环外半径，即相邻原子核心信号可能进入孔径/背景环）；点位表、强度摘要、CSV 与元数据同步标记。
- 截断判定对称化：孔径截断对四条边统一使用像素中心标准（此前左边容忍 1 px、右边 0 px，同一帧内标准不一致）。
- 会话保存/加载：全部参数、选区、标记规则与逐帧原子（含手工修订与 QC 字段）可保存为 `.session.json` 并完整恢复；原始 TIFF 移动后可重新定位，帧数/形状不匹配时拒绝加载且不破坏当前状态。
- 关闭窗口时若有未保存的手工修订，弹出三选确认（保存会话退出 / 直接退出 / 返回）。

算法与性能：

- 跨帧 ID 轨迹老化：连续 8 帧未匹配的轨迹从目录剔除（`link_frame_points(max_missed=8)`），防止误检噪声点无限累积导致匈牙利分配逐帧膨胀；漏检不超过 8 帧仍恢复原 ID。
- 手动点击精炼改为局部 ROI（`refine_point_on_work`），不再每次点击对整幅图做反射填充；显示归一化增加单帧缓存，帧切换与连续点击不再重复计算全帧分位数。
- 检测阈值校验收紧：亮原子模式下 0 与负数阈值直接拒绝（此前 0/负绝对值被接受但匹配一切像素，无意义）；报错文案按极性分别说明分位数/绝对值语义，不再给出"亮原子改用值域内绝对值"这类不可执行的建议。

逻辑与交互修复：

- 撤销语义三连：撤销现在一并回滚 `frame_edited` 与快照时的强度参数（溯源不再失真）；单帧识别只清空该帧的撤销历史，不再波及其他帧的手工修订；全帧重算后旧撤销快照整体失效并明确提示。
- 矩形选区仅响应左键释放完成。
- 全部数值输入解析失败时给出带字段名的中文错误（此前 Excel 风格英文 `could not convert string to float` 直达用户）。

工程与安全（对应外部工具集审查报告横向建议）：

- 导出原子化写入：CSV、元数据、标记 PNG 与标记堆栈 TIFF 全部改为"同目录临时文件 + `os.replace`"，失败/取消不再留下半成品目标文件。
- 导出预检：写权限（`os.access`）与磁盘空间（按未压缩大小保守预估）不足时以中文错误拒绝，不再写一半才失败。
- CSV 公式注入防护：规则名等用户自由文本以 `=`/`+`/`-`/`@`/Tab 开头时加单引号转义。
- 逐帧状态收敛为 `_reset_frame_state` 统一入口，消除多个平行列表手动同步导致的长度不一致缺陷（该缺陷曾使测试套件确定性失败）。
- 界面节奏常量集中命名（轮询 80ms、防抖 120ms、撤销上限 100、轨迹老化 8 帧）；`tifffile` 依赖增加上界 `<2027`。
- 测试套件从 46 个（1 个确定性失败）扩展到 65 个并全部通过：新增阈值语义、截断对称性、邻居污染、轨迹老化、局部精炼等价性、会话往返、撤销语义、导出预检与 CSV 安全测试；修复共享 Tk 会话下测试类状态泄漏与真实模态弹窗挂起测试进程的问题。

## v1.2

稳定性与正确性：

- 修复后台任务轮询单点故障：单条消息处理异常不再终止轮询（此前界面会永久卡在忙碌状态）。
- 新增滚动日志（`%LOCALAPPDATA%/AtomicRecognitionTool/app.log`）与全局异常钩子；无控制台的打包 exe 中异常不再静默丢失。
- 修复快捷键劫持输入框：在文本输入框中打字时 a/d/c/Ctrl+Z/Esc/Enter 全部不再触发工具快捷键，Ctrl+Z 保留文本撤销语义。
- 修复强度参数双真相源：手动添加/删除原子前强制解析右侧卡片输入框，避免沿用过期孔径。
- 检测强度阈值 ≥1 直接校验拒绝并说明语义（阈值作用于 0–1 归一化图像），消除"永远检不出"的静默失败；参数提示与状态摘要同步修正。

数据完整性与溯源：

- 积分强度增加 QC 诊断：每原子输出孔径像素数、背景像素数、背景中位数与"孔径截断"标志（孔径/背景环被图像边缘裁剪或含非有限像素）。截断原子按 v1.1 口径仍参与百分位排名（仅标记不剔除），点位表、图像灰圈、强度摘要与 CSV 同步标记。
- CSV 新增"来源"列（自动/手动）；元数据增加工具版本、导出时间、逐帧检测参数与手工修订帧列表。
- 校准统计只计入 ROI 可靠的点击点（贴边等无效 ROI 不再污染峰值/FWHM 统计），`sample_count` 语义改为实际参与统计的样本数，并在参数窗口显示；新增低对比度提示。
- 修复 RGB TIFF 归一化后内存映射句柄无法关闭的问题；TIFF 规范化失败时显式释放句柄。

性能：

- 重新关联 ID 与 CSV 导出改为后台线程执行（可取消），大堆栈不再冻结界面；忙碌期间同步禁用重算与导出按钮。
- 二维高斯定位中拟合失败的点改为一次性批量 COM 回退，避免逐点对整幅图填充内存。
- 百分位规则校验移出逐记录循环；门控匈牙利匹配逻辑去重。
- 帧滑条与标记大小滑条重绘增加 120 ms 防抖。

## v1.1

## v1.0

- 首个稳定独立版本。
- 支持单张/堆栈 TIFF、逐帧识别、校准、手工增删、稳定 ID、局部积分强度、单帧百分位筛选、标记样式与 TIFF/CSV 导出。
- 支持矩形及自由多边形选区，并可选择仅限制当前帧或应用于逐帧识别全部。

后续每次功能变更都会提升一个小版本号并在此记录；纯修复也会保留对应版本记录。
