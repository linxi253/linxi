# 原子识别与原子柱强度分析工具 v1.3

这是从 PPA 中独立出的传统原子识别工具，界面沿用 PPA 的深蓝标题栏、Material 配色、左图右控件卡片布局。工具只做原子识别、逐帧人工校对、原子柱积分强度和标记导出，不包含位移或应变分析。

## 已实现功能

- 导入单张 `.tif/.tiff` 或多页 TIFF 堆栈；优先使用 `tifffile.memmap`，压缩 TIFF 自动回退到普通读取。
- 复用 PPA 的传统识别流程：高斯预滤波 → 局部极值 → 贪心 NMS → COM/二维高斯亚像素定位。
- 检测强度阈值作用于 1%–99% 归一化后的显示图像：留空为自适应（P80），填 0–1 之间的小数按分位数解释（如 0.6 = P60）；亮原子没有独立于分位数的绝对阈值区间（0 与负数会被直接拒绝），暗原子可额外使用 -1–0 之间的绝对值。
- 二维高斯亚像素定位中拟合失败的点会批量回退到 COM 精炼，大图上不再逐点重复内存填充；手动点击的 COM 精炼只裁剪局部窗口，不再对整幅图做反射填充。
- 保留 PPA 校准功能：在当前帧点击 2–4 个相邻原子并按 `Enter`，自动估计最近邻间距、FWHM、滤波参数、质心窗口、检测阈值、积分孔径和跨帧 ID 距离。
- 校准完成后自动打开参数确认窗口，可在识别前微调校准建议；窗口同时提供识别/亚像素定位参数与积分强度/跨帧 ID 参数，并可选择“仅应用参数”或“应用并识别当前帧”。
- 识别当前帧或在后台逐帧识别整个堆栈，支持取消。
- 支持矩形选区和自由多边形选区，选区在局部极值候选阶段限制自动识别范围；手工添加、删除不受选区限制。
- 选区可选择“仅限制当前帧识别”或“逐帧识别全部中应用”：前者允许每帧保存独立选区，只在识别当前帧时生效；后者把当前公共选区应用到当前帧识别以及整个堆栈的每一帧。
- 每帧独立手动添加、删除和撤销原子点；右键可直接删除最近原子。撤销会一并回滚该帧的"手工修订"溯源标志与当时的强度参数；单帧识别只清空该帧的撤销历史。
- 对漂移矫正后的堆栈按位置进行一对一 ID 关联；轨迹连续 8 帧未匹配即从目录剔除（防止误检噪声点无限累积），漏检不超过 8 帧仍恢复原 ID。
- 计算每个原子对应的局部背景扣除积分强度，并与帧号、稳定 ID、亚像素位置一一对应。
- 每一帧内部独立计算强度百分位。低百分位表示该帧中较弱的原子柱。
- 动态添加多个百分位显示规则，每条规则可独立设置范围、颜色、圆圈/方框/三角形/菱形/叉号/加号/星形以及显示状态。
- 保存当前帧标记图；导出无坐标轴的 8 位 RGB 带标记 TIFF 堆栈。
- 导出逐帧坐标、ID、积分强度、单帧百分位、QC 诊断（孔径/背景像素数、背景中位数、截断标志、最近邻距离与邻居污染标志）、来源（自动/手动）、本帧强度参数指纹和命中标记规则的 CSV，同时写出包含工具版本、导出时间、逐帧检测/强度参数与手工修订帧列表的 `.metadata.json` 旁车文件。
- 会话保存/加载：全部参数、选区、标记规则与逐帧原子（含手工修订）保存为 `.session.json`，可随时恢复；关闭窗口时若有未保存修订会弹三选确认。
- 逐帧识别全部、强度重算、重新关联 ID、带标记堆栈导出与 CSV 导出均在后台线程执行，可取消，界面不冻结。
- 所有导出（CSV/元数据/PNG/堆栈 TIFF）采用"临时文件 + 原子替换"写入，失败不留半成品；导出前检查写权限与磁盘空间。
- 未捕获异常会写入 `%LOCALAPPDATA%/AtomicRecognitionTool/app.log` 滚动日志并在界面提示，打包 exe 中不再静默失败。

## 原子柱积分强度定义

工具始终保留 TIFF 原始像素数值。1%–99% 显示归一化只用于预览和原子检测，不参与定量强度积分。

对每个亚像素原子位置 `(x, y)`：

1. 在用户设定的圆形孔径内取像素；
2. 在同心背景环中取局部背景中位数 `bg`；
3. 亮原子计算 `Σ(I - bg)`，暗原子计算 `Σ(bg - I)`；
4. 不对单像素差值截零，以免给噪声引入系统性正偏差；
5. 在当前帧的全部有限积分强度中计算百分位秩。

**孔径截断标记（v1.2）**：孔径或背景环被图像边界裁剪（按像素中心标准，四条边同一判据）、或范围内含非有限像素时，该原子标记为"截断"。截断原子的强度系统性偏低，但按 v1.1 口径**仍参与百分位排名**（仅标记不剔除）：点位表增加"截断"列，图像上叠加灰色虚线圈，强度摘要提示数量，CSV 输出孔径像素数、背景像素数、背景中位数与截断标志，供人工判断是否采信。

**邻居污染标记（v1.3）**：当同帧最近邻原子距离小于"孔径半径 + 背景环外半径"时，相邻原子的核心信号可能进入本原子的孔径或背景环，强度与背景估计都可能被抬高或压低。此时标记"邻居污染"并输出最近邻距离（点位表、强度摘要、CSV 与元数据同步），采信此类强度前应人工核查。

**逐帧强度参数溯源（v1.3）**：识别、重算、手动增删与重新关联都会记录各帧实际使用的强度参数。CSV 每行附带"本帧强度参数"指纹；若中途修改孔径只重算了部分帧，`.metadata.json` 的 `intensity_params_consistent_across_frames` 会标记为不一致，各行参数差异可直接审计。

孔径半径、背景环内/外半径都可在界面直接修改，并可重算当前帧或全部帧。不同数据集比较时应保持这些参数一致。

## 选区识别

- 先选择“仅限制当前帧识别”或“逐帧识别全部中应用”，再绘制选区。
- 矩形选区：按住左键拖拽，松开后完成。
- 自由选区：依次左击添加顶点；双击、按 `Enter` 或再次点击“完成自由选区”闭合；右键撤销最后一个顶点。
- 按 `Esc` 可取消尚未完成的绘制；“清除选区”只清除当前作用范围对应的选区。
- 橙色边界表示当前帧独立选区，青色边界表示逐帧共用选区。
- 选区只决定自动识别哪些候选原子，不裁切原图，也不会隐藏已经存在的手工点。导出的 CSV 元数据会记录公共选区及逐帧选区顶点。

## 跨帧 ID 规则

第一帧按图像中的空间顺序分配 ID。后续每帧使用一对一最小距离匹配，并只接受“跨帧 ID 距离”以内的对应关系；未匹配点得到新 ID。轨迹连续 8 帧未匹配后从目录剔除（避免误检噪声点无限累积、拖慢匹配并稀释 ID 语义），因此漏检不超过 8 帧的原子仍恢复原 ID；超过 8 帧的同位置点会得到新 ID。工具适合已经完成漂移矫正、同一原子位置基本不变的堆栈。

手动添加点时，程序会先尝试复用其他帧同位置且本帧尚未占用的 ID；否则分配新 ID。手动删除只影响当前帧。需要整体重建时可点“重新关联 ID”。

## 会话保存与恢复

“保存会话”把当前全部状态（识别/强度参数、跨帧距离、标记规则与大小、选区、每帧的原子记录与 QC 字段、逐帧参数溯源、手工修订标记）写入 `.session.json`；“打开会话”完整恢复。会话只保存坐标与结果，不复制原始 TIFF——重新打开时需要原始文件还在（被移动过时可重新定位）；帧数或形状与原始 TIFF 不一致时拒绝加载，且不会破坏当前工作状态。关闭窗口时若有未保存的手工修订，会提示选择保存退出、直接退出或返回。

## 百分位筛选示例

若预览只想保留每帧强度较弱的 10%–20% 原子：

1. 双击默认“全部原子”规则；
2. 把下限改为 `10`、上限改为 `20`；
3. 选择颜色和形状后保存。

此时原子数据不会被删除，只是预览、当前帧标记图和带标记堆栈只绘制命中范围的原子。规则可重叠；重叠时按列表从上到下第一个命中规则生效。

## 文件说明

- `atomic_core.py`：无 GUI 依赖的 TIFF、原子检测、积分强度、百分位、ID 关联和标记渲染算法。
- `atomic_app.py`：Tkinter/Matplotlib 图形界面、逐帧任务和导出。
- `tests/test_core.py`：核心算法单元测试。
- `原子识别与强度分析工具.spec`：PyInstaller 打包配置。
- `CHANGELOG.md`：按小版本记录每次功能变更；后续更新将继续递增版本号。

## 注意事项

- 带标记 TIFF 是用于检查和展示的 8 位 RGB 可视化结果，不能代替原始 TIFF 做定量强度分析；定量结果请使用 CSV 和原始图像。
- 检测阈值作用于 1%–99% 归一化后的显示图像而非原始灰度：0–1 之间一律按分位数解释（与极性无关）；亮原子没有独立于分位数的绝对阈值区间，0 与负数会被校验拒绝；暗原子模式下图像取负（值域 -1–0），可使用 -1–0 之间的绝对值。
- 跨帧 ID 依赖输入已经漂移矫正。若帧间位移超过设定距离，会分配新 ID；若距离设得过大，相邻原子可能发生错误对应。连续 8 帧未匹配的轨迹会被剔除，超长漏检的同位置点将获得新 ID。
- 背景环应位于原子柱信号外、相邻原子柱信号内。校准会给出建议值，但最终应结合样品晶格间距和成像条件检查。
- 校准统计只使用 ROI 可靠的点击点（贴边或无效 ROI 会被剔除）；参数确认窗口会显示实际参与统计的样本数，样本峰值与噪声接近时会提示低对比度。
- 手动添加点会按当前 COM/二维高斯参数做一次亚像素精炼，因此 CSV 中的位置可能与鼠标点击位置略有不同；手动添加的原子在 CSV"来源"列标记为"手动"。
