# 应变分析

本分类含 4 个子项目，其中提供两条互补的二维应变分析路线：

- [Strain++ GPA](strainpp-GPA应变分析/README.md)：在频域选择两个非共线 Bragg 斑点，通过几何相位计算位移和应变场。
- [PPA 原子级分析](原子级应力分析-PPA/README.md)：在实空间检测原子柱，拟合理想晶格，再计算原子位移和局部应变张量。

另有两个配套子项目：

- [原子识别纯算法](原子识别纯算法/README.md)：从 PPA 独立出的传统原子识别与原子柱积分强度工具，只做识别、逐帧人工校对、强度积分与标记导出，不包含位移或应变分析。
- [原子中心识别模型开发](原子中心识别模型开发/README.md)：HAADF-STEM/HRTEM 原子中心深度学习模型的独立训练与评测仓库（数据治理、YOLOv8 训练、manifest 发布），PPA 稳定版只消费其带 SHA-256 的发布模型。

GPA 适合晶格条纹清晰、FFT 斑点明确的 HRTEM 图像；PPA 适合原子柱可可靠定位的 HRTEM/HAADF-STEM 图像。两者均需要无应变参考区、像素标定和独立的物理合理性检查。
