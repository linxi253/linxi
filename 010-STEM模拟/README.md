# 010-STEM 模拟工具（HAADF-STEM，冻结声子多层法）

基于自研引擎 **stem_sim** 的 STEM 图像模拟 GUI：导入 CIF/PDB/XYZ 晶体模型，
选择带轴与样品厚度，设定探针（会聚角、球差、离焦、束倾斜）与环形探测器
（HAADF 内/外角），用**冻结声子多层法**计算原子分辨率的 HAADF/ADF 图像，
并同时输出 BF/ABF。

与 [09-HRTEM模拟](../09-HRTEM模拟) 同源：共享同一套电子散射因子（Peng 1999
标准表）、晶体带轴重构与显微光学参数定义；本工具在其上增加了 STEM 专有的
会聚探针、批量探针多层法、热漫散射（冻结声子）与环形探测器。

## 启动

```
run.bat
```
或
```
python stem_tool/main.py
```

依赖：numpy、scipy、matplotlib、Pillow、ase（读 CIF）、ttkbootstrap（界面主题，可选）、
pyfftw（**强烈推荐**，批量 FFT 比 scipy 快 4–11 倍）。
运行环境为本项目独立的 `.venv`（Python 3.10），依赖锁定在 `requirements.lock.txt`。

> （例如 numpy 1.26 与 2.2 并存），共用解释器会让工具读到别的项目的依赖版本，
> 并且 `pip install` 会污染全局环境、连带破坏其它工具。

首次准备环境（只需一次）：

```bat
python -m venv .venv
.venv\Scripts\python -X utf8 -m pip install -r requirements.lock.txt
```

之后双击 `run.bat`，或用项目内解释器启动：

```bat

```

## 物理与算法

对每个探针位置、每个声子组态：

1. **探针** ψ₀(r) = F⁻¹[A(k)·exp(−iχ(k))]·e^(−2πi k·r_p)，归一化 Σ|ψ₀|² = 1
   （χ 含球差、离焦、二重像散；束倾斜 = 孔径在倒空间平移）
2. 逐片：ψ ← ψ·t_j（透射函数），ψ ← F⁻¹[F[ψ]·P(Δz)]（菲涅尔传播）
3. 出射波倒空间强度 |F[ψ_exit]|² 与探测器掩模内积 → 该点的收集比例
4. 对 N 个声子组态的**强度**求平均（不是对波函数求平均）

关键实现点：

- **热位移**：Debye 模型 B = (6h²/(m k_B Θ_D))·[φ(Θ_D/T)/(Θ_D/T) + 1/4]，
  σ_u = √(B/8π²)，逐方向独立高斯（非关联冻结声子，HAADF 的标准做法）。
  Au(300 K, Θ_D=165 K) 给出 B = 0.648 Å²、σ_u = 0.0906 Å（实验 B ≈ 0.5–0.7 Å²）。
- **批量探针**：一次 FFT 同时传播 B 个探针位置，配合 pyfftw 多线程；
  网格尺寸向上取 **5-光滑数**（避开 FFTW 的慢质因子，实测 306² → 320² 快 1.57 倍）。
- **透射函数跨探针复用**：与探针位置无关，一次构建全部探针共用。
- **厚度序列免费**：传播循环中每片之后本就要做一次正变换，在这些位置顺带
  累加探测器信号即得任意切片边界的厚度序列。
- **并行**：任务按 (声子组态, 图像行块) 切分交给进程池；实测 24 核下
  8 进程 × 3 线程相对单进程 8 线程约 **3.8×** 吞吐。

输出强度单位是**入射束流被探测器收集的比例（0–1）**，因此可跨厚度/参数直接
比较（薄区 ADF ∝ 厚度，可用于厚度标定）。

## 参数约定（务必注意）

- **离焦**：正 = 过焦，负 = 欠焦。
  探针最优离焦 Δf = −√(|Cs|λ)；TEM 相位衬度的 Scherzer 离焦是 −√(1.5|Cs|λ)，
  两者**不同**——界面上的「Scherzer」按钮给的是探针口径。
- **球差 Cs**：单位 mm，1 mm = 1e7 Å；负值 = 校正器过校正。
- **探测器外角 ↔ 采样（HAADF 最关键的自洽约束）**：
  FFT 网格的奈奎斯特频率对应 sinθ_max = λ/(2Δx)，故
  **Δx ≤ λ/(2·sinθ_外)**。200 mrad@300 kV 要求 ≤0.047 Å/px；100 mrad 要求 ≤0.094 Å/px。
  超过奈奎斯特的强度是混叠结果，工具会裁剪并明确提示。外角越大 → 采样越细 →
  网格点数平方增长 → 这是 HAADF 模拟最主要的代价来源。界面「自定采样」时
  按外角反解（留 5% 余量）。
- **扫描视场**对耗时最敏感（网格点数 ∝ 视场²）。原子分辨率 HAADF 视场通常
  1–5 nm，不是几十 nm。超胞横向尺寸取扫描视场，扫描区域在超胞内居中。
- **探测器内角**建议 ≥ 2–3 倍探针角（HAADF 常规 60–200 mrad）；内角接近探针角
  会混入较多弹性/布拉格散射，Z 衬度减弱。
- 面内旋转为绕光轴逆时针；镜像为水平翻转（与实验图对齐用）。

## 与 09-HRTEM模拟 的差异（重要）

两个同源引擎的 `phase_kernels` 曾存在一处相位标度错误——**09 已于 2026-10
同步修复**（与本工具一致，见其 README「相位标度修正」），本节保留完整记录，
务必阅读：

`phase_kernels` 曾返回**像素积分**（∫K = γλ·a_i，求和规则正确），但透射函数
t = exp(iφ) 需要的是**连续相位在像素上的平均值**（等价于在像素中心采样），
两者相差一个像素面积 Δx·Δy。旧实现把像素积分直接当相位用，导致相位
**小 Δx² 倍**：0.1 Å/px 下小 100 倍，0.07 Å/px（09 工具默认）下小 204 倍。

影响与为何长期未被发现：

- 透射函数的调制几乎消失 → 高角散射强度低约 4 个量级，
  ADF 强度比运动学估计低约 10⁴ 倍；
- 动力学（多重散射）效应被压制，引擎实际只在弱相位物体（单散射）极限下工作；
- 而既有验收指标**全部对整体标度不敏感**：归一化图像的 NCC 是尺度无关的，
  平均内电位 V0 = Σφ/(σV) 也只用积分的和（两种口径下都正确）。
  故 09 的 `NCC = 1.000000` 与 `V0(Al) = 17 V` 都无法发现该错误。

判定性证据（`tests/verify_physics.py` 第 2b 项）：单个 Au 原子的投影势相位
峰值有解析值 γλ·π·Σ(a_i/b_i) = **3.4713 rad**（≈π，对应"重原子中心透射函数
近 −1"的教科书结论），且必须与采样无关。旧实现在 0.1 Å/px 下只给出
**0.0218 rad**（且随 Δx² 缩放）。

修正：`scattering.py` 的核额外除以像素面积（本工具先行，09 的
`tem_sim/scattering.py` 已于 2026-10 同步修复，并补上与本文 2b 项同款的
解析峰值判据自检），修正后峰值随采样收敛到解析值（0.02 Å/px → 3.381 rad，
残余 2.7% 来自宽尾项的相位阈值截断），且求和规则 Σφ = γλ·f_e(0)/(Δx·Δy)
精确成立。

**遗留影响**：若 09 的交付结果是在旧口径下寻优得到的，仍需重新标定——
其 README 已记录"标准表下 (厚度, 离焦) 二维重扫 best NCC(实验) ≈ 0.35"，
与相位标度错误导致动力学效应缺失的预期一致。

## 绝对强度标度（登记在案）

对薄样品，ADF 收集比例 F 与"运动学单散射"估计的关系为

    F ≈ K · σ_ADF · n_areal ,   σ_ADF = ∫|f_e|²dΩ（探测器角度范围）

本引擎给出 **K ≈ 2.2**（Peng 表、0.1 Å/px），与厚度/密度/有序度无关。
来源是多层法相互作用常数 σ = 2πγmeλ/h² 与散射因子表口径的组合
（γ² = 2.52 @300 kV，扣除像素带限的 sinc² 损失后约 2.2）。

**这是约定而非误差**，依据是：

- 与 abTEM（领域标准实现）的**投影势积分一致到 0.09%**（505.74 vs 505.27 V·Å³），
  即两者的势场标度与相位口径完全相同；
- 与 abTEM 的 **Z 衬度指数一致**（1.76 vs 1.71）。

定量对比实验绝对强度时按 K 换算；只比相对衬度时可忽略。
（`tests/verify_physics.py` 第 13 项把 K 登记在 [1.6, 2.6] 内，任何改动都会被捕捉。）

## 已知边界（引擎未实现）

- **部分相干**：源尺寸（有限角展宽）与能量展宽未实现，故不模拟会降低衬度的
  部分相干效应。「显示模糊」只是经验性的图像后处理模糊，不是物理模型。
- **分段探测器**：四象限/环形分段的**对向差分 ABF**、DPC（差分相位衬度）
  的一阶矩信号未实现（需要改变探测器几何而非仅掩模）。本工具的 ABF 是
  常规的环形亮场（收集亮场盘外圈 0.6α–α）。
- **声子色散关联**：热位移取非关联高斯（只保留 Debye-Waller 因子），
  不产生 Kikuchi 带等关联效应。HAADF 高角 TDS 对此不敏感，属通行做法。
- **带轴重构要求公度取向**：非公度会明确报错，需手工构建取向超胞后用
  PDB/XYZ 导入。
- **高阶像差**（C32 等）、**三维缺陷/非周期结构**（当前是周期超胞模型，
  「立体缺陷图」只是把 ADF 强度画成 3D 曲面，不是三维重构）。
- **大视场不可行**：单轴网格上限 4096（HAADF 原子分辨率视场本就只需几 nm）；
  横向尺寸/采样超出会明确报错而不是静默耗尽内存。
- 采样过粗（>0.15 Å/px）或像素无法分辨最窄散射项时会低估高角散射；
  界面会给出"实际采样"与奈奎斯特上限供核对。

## 性能参考（本机：24 物理核，pyfftw 8 线程）

Au [100]、300 kV、Cs=0.01 mm、探针 25 mrad、探测器 50–100 mrad、t=10 nm、
视场 2 nm、40² 扫描点、8 声子组态、网格 225²、41 切片 → **约 30 s**。

耗时近似 ∝ 扫描视场² × 扫描点数² × 声子组态数 ÷ 切片厚度 ÷ 探测器外角²
（最后一项来自"外角越大要求采样越细"）。界面「模拟计划」面板给出实时预估，
预估偏差约 ±30%（实测校准：360² 网格/51 切片/8 组态/32² 探针（16 进程）预估 324 s、实跑 261 s；
256² 网格同规模（8 进程）预估 108 s、实跑 136 s）。结果里会同时记录**实测 FFT 速率**，便于核对。

## 环境变量

| 变量 | 作用 |
|---|---|
| `STEM_FFT_THREADS` | FFT 线程数（默认 min(8, 核数)） |
| `STEM_MEMORY_MB` | 内存预算上限（MB）；默认取可用内存的 40%，上限 3 GB |
| `STEM_NO_MP` | 设为任意值即禁用多进程（退回串行） |

多进程注意事项：Windows 上只能用 spawn，**调用 `stem_scan` 的脚本/模块必须带
`if __name__ == "__main__":` 守卫**，否则子进程会重新执行主模块顶层代码
（重复模拟甚至进程爆炸）。引擎会检测该守卫，缺失时自动退回串行并在结果
notes 中说明；`stem_tool/main.py` 已带守卫。

**从源码运行**——必须使用本工具自己的虚拟环境，不要用 PATH 上的 `python`：
各工具依赖版本互不相同，共用解释器会互相污染。

```powershell
cd <本工具目录>
python -m venv .venv
.venv\Scripts\python -X utf8 -m pip install -r requirements.lock.txt
.\run.bat
```

`run.bat` 检测到环境缺失时会打印重建指引，不会静默回退到 PATH 上的解释器。

**未纳入版本控制**：`.venv/`、`build/`、`dist/`、`release/`、`__pycache__/`、
测试数据与运行输出。具体规则见本目录 `.gitignore`。
