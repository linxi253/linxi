# 4D-STEM 分析

本分类的当前项目是 [4D-STEM-Processor](4D-STEM-Processor/README.md)，用于读取 DM4 四维数据并执行 DPC/iDPC、SSB、应变、取向、峰对和 ePIE 分析。

附带文件（未入库，不在本仓库中，可在提交历史/内部归档中查找）：

- `4D-STEM处理完整对话记录.md`：开发过程和问题排查记录（未随仓库分发）。
- `原始对话记录.jsonl`：更完整的原始对话日志，体积较大，主要用于追溯开发过程（未随仓库分发，且被根 .gitignore 的 `*.jsonl` 规则排除）。

对日常使用，应先阅读项目 README；两份对话记录不是运行依赖，仓库内也无副本。
