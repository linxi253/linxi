# 统计分析

本分类包含四个互相独立的 TIFF 定量分析工具。

- [原子衬度统计](原子衬度统计/README.md)：多 ROI、逐帧衬度曲线和 CSV 导出。
- [特征区域演化分析](特征区域演化分析/README.md)：HAADF-STEM 时间序列的区域面积、强度和高级统计图。
- [统计面积](统计面积/README.md)：手工多边形面积测量、标尺校准及项目保存。
- [非晶面积统计](非晶面积统计/README.md)：晶体/非晶区域自动分割、面积与生长速率统计。

这些工具使用的“面积”定义不同：手工多边形、阈值特征区域和晶体/非晶分割不可直接混用。比较结果前应统一标尺、阈值、时间间隔和预处理方法。
