# 电镜晶体/非晶区域统计分析工具 v5.3

批量读取 TIFF 图像或堆栈，通过五种分割方法区分晶体和非晶区域，计算面积、周长、形状因子及时间序列生长指标。

## 直接运行

本仓库不含构建产物（无 `dist/` 目录），历史上分发的 `dist/电镜晶体非晶区域统计分析工具v5.2.exe`
未随仓库分发。需要 exe 请用 `非晶面积统计工具.spec` 自行打包
（v5.3 源码修复后尚未重新打包；历史 v5.2 exe 不含 RGB 预览修复、14-bit 分档、
逐区域面积口径、生长速率口径统一等更新，不要继续使用旧版 exe 的输出）：

```powershell
.venv\Scripts\python -m pip install pyinstaller
.venv\Scripts\python -m PyInstaller 非晶面积统计工具.spec
```

（v5.1 及更早版本的旧 exe 归档在开发机的 `<仓库根>\08-历史版本\旧版exe\`，该归档未随本仓库分发。）

## 从源码运行

建议 Python 3.10 或 3.11：

```powershell
python -m pip install -r requirements.txt
python .\main.py
```

Windows 也可运行 `install_deps.bat` 安装依赖。

## 分割方法

- 固定阈值；
- Otsu 自动阈值；
- 自适应阈值；
- Canny 边缘检测与轮廓填充；
- Watershed 分水岭。

界面可预览分割结果，再批量处理输入目录中的 `.tif/.tiff` 文件。分割方法下方可
选择**前景极性**：亮区为晶体（HAADF/暗场默认）或暗区为晶体（TEM 明场衍射衬度
下晶体区域常更暗）。

## 统计口径（重要）

- 所有分割均为**灰度阈值判据**。"晶体区域"的严格含义是"高衬度区"，
  不是晶体学鉴定；请结合衍射/成像模式解读。
- **"非晶区域"是晶体掩膜的补集，包含真空、支持膜和孔洞**，未做背景剔除。
  请勿将"非晶面积"直接作为非晶相的物理面积引用；该口径警告也会写入
  Excel 的"实验参数"工作表。
- uint16 输入按**整个输入目录**的数据量程统一缩放到 8 位（同批数据共用一个
  映射，12-bit 相机数据不再被固定 /256 压缩到 0-15，14-bit 量程走独立
  分档不再被压到 0-63；含 NaN/Inf 的 float 输入按背景处理后照常分割并在
  日志中告警；int/float 等非固定位深输入按单图归一化时日志会给出
  跨切片可比性告警）。
- "晶体区域数量"、周长与形状因子只统计 ≥3 像素的连通区域，口径一致
  （3 像素的线状区域也计入，形状因子为 0）；面积按全部前景像素计数
  （含 <3px 噪斑）。
- 逐区域导出中的"面积(px)"是**像素计数**，与聚合面积同口径；
  周长与形状因子基于轮廓多边形（两者互相自洽），与面积列口径不同，
  属预期，勿用形状因子反推面积。

## 标定纪律

界面中像素尺寸默认**未标定**：此时像素尺寸锁定为假定值 1.0 nm/px，
面积/周长的实际单位应读作 px/px²，CSV 会附带"像素尺寸标定"列，
Excel 参数表会给出警告。勾选"已标定"后才可输入实测 nm/px 并按 nm²
引用绝对面积。

## 输出

- UTF-8-SIG CSV（含"像素尺寸标定"列）；
- 逐区域 CSV（`region_results_*.csv`：每个连通区域的面积/周长/形状因子/
  质心/外接框；行数受控时同步写入 Excel"逐区域数据"表）；
- 多工作表 Excel，包括原始数据、形状因子、生长分析、逐区域数据和实验参数
  （含前景极性、**全部分割方法参数**、最小区域像素数、标定状态与统计口径
  警告，结果可完整复现）；
- `annotated_tif/` 中的逐帧标注 TIFF；
- 可选运行日志；
- 界面配置跨会话持久化（`%APPDATA%\EMAmorphTool\config.json`）。

面积换算和生长率依赖界面中的像素尺寸与帧间隔，必须使用实验标定值。

## 项目结构

- `main.py`：应用入口。
- `constants.py`：版本、默认参数、分割方法、结果列名 schema 与界面常量。
- `core/segmentation.py`：五种分割算法、位深自适应（数据集级）与前景极性。
- `core/measurement.py`：面积、周长、形状因子与逐区域测量。
- `core/analysis.py`：时间序列、生长分析与形状一致性/时序稳定性。
- `core/logger.py`：线程安全日志。
- `gui/app.py`：主窗口和批处理流程。
- `gui/parameter_panel.py`：分割参数面板（含前景极性）。
- `gui/canvas_viewer.py`：图像显示、缩放和平移。
- `io_utils/tiff_handler.py`：TIFF 读取、位深扫描与标注写出。
- `io_utils/exporter.py`：CSV/逐区域 CSV/Excel 导出。
- `io_utils/app_config.py`：配置持久化。
- `requirements.txt`、`install_deps.bat`：依赖安装。
- `非晶面积统计工具.spec`：PyInstaller 配置。
- `dist/`：打包产物目录，未入库，需用上述 spec 自行构建。
- `数据说明.txt`：当前为空文件，仅保留原始命名记录。

## 注意事项

- 不同分割方法的边界定义不同，结果不可在未统一方法和参数时直接比较。
- Otsu 只对双峰或可分离灰度分布较可靠；低信噪比数据应人工检查掩膜。
- 标注图是可视化结果，定量数据以 CSV/Excel 为准。
- 对外报告应记录分割方法、阈值、前景极性、最小面积、像素尺寸、标定状态和时间间隔
  （v5.2 起全部参数随 Excel"实验参数"表自动落盘）。
- "区域形状一致性"衡量**切片内**区域间形状离散度；形状随时间的演化请看
  "形状因子时序稳定性(CV)"。两者含义不同，勿混用。

## 更新记录

- **v5.3**（2026-09-28，源码；对齐《电镜分析工具代码审查报告》+ 本轮深度审查）：
  - **修复 RGB 单页 TIFF 预览错乱**：预览路径曾把 (H,W,3) 彩色图当作 H 个
    "切片"（每片是一行条带），预览/"分析当前"对垃圾数据出结果；批量路径
    不受影响。现切片数优先取 TIFF 元数据口径，数组层同口径判定；
  - **修复重置视图丢失数据集级位深映射**：窗口 resize / "重置视图"后
    uint16 位移回退到单图自动判定，12-bit 数据集暗切片亮度跳变 16 倍；
  - **预览性能**：数据集级位移在加载时计算一次并缓存（此前每次切片
    导航都全量扫描堆栈）；>2GB 文件载入预览前先确认（内存护栏）；
  - **14-bit 数据支持**：位深分档补 0-16383 档（右移 6 位），14-bit
    相机数据不再被 >>8 压到 0-63 导致固定阈值静默全灭；
  - **生长速率口径统一**：Excel 生长分析表的均值/最大/最小全部只统计
    有效差分行（此前均值排除了首行回填值与单切片 0 值行，最值没有）；
    逐文件行的速率列不再恒空；参数表新增"生长速率口径说明"；
  - **逐区域面积改为像素计数**：此前用轮廓多边形面积（contourArea），
    10×10 方块记 81px 而聚合记 100px，逐区域面积系统性偏低约 19%；
    3 像素线状区域不再被静默丢弃（符合 ≥3px 计入口径）；
  - **关窗安全**：批量处理中退出时等待后台导出收尾再销毁窗口，
    不再硬杀 daemon 线程留下半写损坏的 Excel/TIFF；
  - **批量目录快照+锁件**：输入/输出目录在启动时快照并在处理期间锁定，
    中途改目录不再导致 CSV 与标注图写到不同位置；导出前增加写权限检查；
  - 位深扫描跳过的损坏文件现在如实列入日志告警（此前静默）；
  - 自适应阈值块大小运行时钳位到图像短边；日志 Text 控件与内存列表
    同步裁剪；合并三处重复的"分割+测量"代码与双轨聚合实现；
  - requirements 锁大版本上界（精确复现用 requirements.lock.txt）。
- **v5.2**（2026-09-06，源码）：
  - 修复标注图叠加公式：全零 overlay 混色曾把掩膜外像素整体压暗 35-40%，
    改为"原图着色副本"逐像素混合，标注图恢复真实衬度（可视化行为变化：

  - 新增逐区域数据导出（CSV + 受控行数的 Excel Sheet）；
  - "形状稳定性"正名为"区域形状一致性"（切片内离散度），新增"形状因子
