# 晶体/非晶区域统计

当前项目源码位于 [pythonProject](pythonProject/README.md) 子目录。外层目录用于按统计主题归类，没有独立入口。

本仓库不含打包产物（`dist/` 未入库，见根 README）：从源码运行的方法见子目录 README；
如需成品程序，请在项目自己的虚拟环境中用 `非晶面积统计工具.spec` 自行打包。

注意：源码为 v5.3，历史分发的 v5.2 exe 不含其更新（RGB 预览修复、14-bit 分档、
逐区域面积口径、生长速率口径统一等，详见子目录 README 的更新记录），
不要继续使用旧版 exe 的输出。

分割方法、输出和文件结构请阅读子目录 README。
