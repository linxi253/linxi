# 非晶面积统计 开发约定

晶体/非晶分割、逐区域几何与时间序列生长统计。 **状态：现有实现。**

公开版位于**统一的 AIforTEM 公开仓库**内（`04-统计分析/非晶面积统计`），使用本项目独立的 `.venv`。

按任务查看 [源码与验证导航](DEVELOPMENT.md)，使用与科学说明见 [README](README.md)。

## 修改边界

- 在**公开仓库根**运行 git status/diff，保留已有修改与未跟踪文件；可读性整理只补导航，不改算法、路径、输出或依赖。
- 使用 .venv/Scripts/python.exe；锁文件与测试前置条件见开发说明，缺失时记录未验证，不回退全局 Python。
- 原始数据、发布成品、权重及历史验证材料保持原样。只读导航无需安装、重打包或执行业务模块。

## 关键行为

- 源码根即本目录（公开版已去掉主源码的 `pythonProject` 层）。
- 亮/暗晶体极性、16 位灰度转换与分割方法共同决定面积；未标定状态不能伪装成实测 nm 标尺。
- 固定阈值判据是 `gray > threshold`（严格大于，默认 128），不是 `>=`。
- uint16 → uint8 的位移按数据集量程选择，必须保证量程顶端映射后**仍高于阈值**（否则固定阈值静默全灭），并且**移位后 clip 到 255**（`astype(uint8)` 会回绕，亮像素变黑）。
- 位移按数据集统一：同一数据集内映射单调、跨切片可比。**不同数据集的 shift 可能不同**，因此固定阈值对应的原始强度在不同数据集上并不相同，跨数据集比较前需确认量程档位一致。
- 不做逐帧自动伸缩；显式传入 shift 与 8-bit 输入的行为保持不变。
- 逐区域面积、有效帧和生长速率定义保持一致；配置持久化与同 stem 输入的输出避让保留。
