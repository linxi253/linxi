# Changelog

## 7.3.0 - 2026-09-28

### 审计与可追溯性

- 版本号收敛为单一来源 `drift_core.__version__`，GUI 标题、pyproject、
  打包资源与批处理审计报告全部由其派生；报告 JSON 顶层新增 tool 与
  tool_version，默认参数变更（如 7.1→7.2）后旧报告仍可追溯。
- 批处理报告逐文件新增 started_at/duration_s/source_size_bytes/source_mtime、
  shift_x_range/shift_y_range（此前只有最大绝对值）与逐帧对质量明细
  pair_quality（特征数/匹配数/内点/内点比例/中位残差/状态/失败原因）。
- 保存与批处理现在同时写出逐帧位移表 `<原名>_corrected_shifts.csv`
  （frame、shift_x_px、shift_y_px、key_frame、segment_estimated），
  插值区段显式标记，可直接导入 Origin/Excel 复核。
- 审计报告 CSV 列序固定（source_path/status 优先），多次运行之间可人工
  对比；单元格级公式引导字符转义防 Excel 注入。

### 内存与批处理防护

- 界面加载改为两段式"先只读元数据"：C/Z 轴确认与大堆栈内存确认都发生
  在整栈解码之前；解码体积超过物理内存 40% 时需人工确认。
- 批处理对解码体积超过物理内存 90% 的文件直接判失败并记录，不再无人
  值守地撞 OOM（物理内存探测经 GlobalMemoryStatusEx，失败时自动跳过
  该检查）。
- 批处理单文件内进度按阶段加权上报（检测 0--0.8、保存 0.8--1），大单
  文件处理期间进度条不再长时间停滞。

### 性能

- 描述子达到 512 对以上时匹配改用 FLANN KD-tree 近似最近邻（失败自动
  回退暴力匹配），大堆栈匹配阶段显著提速；小规模保持 BFMatcher。
- `inspect_stack` 结果可传入 `read_stack(meta=...)` 复用，消除同一文件
  的重复 IFD 扫描（界面加载与批处理各少扫一次）；读入页数与元数据
  不一致时显式失败（防读取途中文件被替换）。

### 界面

- 预览支持拖拽平移：普通模式按住左键拖动即可查看放大后的非中心区域
  （此前 5x 缩放只能看中心）；缩放重置（0/1:1）回到图像中心。
- 漂移曲线以橙色底纹显式标出插值区段；检测警告完整列出（此前只显示
  第一条）。
- 输入/输出目录、文件类型、手动步长与全部参数持久化到
  `~/.drift_correction_v7.json`，重启自动恢复。
- 单帧堆栈直接提示无需检测；矫正预览标题改为"补偿漂移 dx=…, dy=…"，
  不再以取负后的数值误导方向。
- 跳帧上限校验收敛到单文件检测场景；批处理不再用当前文件的帧数约束
  所有待处理文件（各文件由核心层自行退化处理）。
- `logging.basicConfig` 移入 main()，模块被测试/库式导入时不再产生
  全局副作用。

### 一致性与小修

- `_adjust_shift` 与 `_manual_adjust`/`_on_shift_edit` 统一设置
  manual_dirty，消除三入口两种行为的状态机漂移。
- 单页连续三维堆栈的判定提取为 `TiffIO._contiguous_stack_info`，
  inspect 与 read 共用（此前两处逐字重复）。
- 检测关键帧形状在任务派发前于主线程确定，消除 worker 内对 key_shape
  共享赋值的竞态。
- `write_stack` 前置检查输出目录写权限（os.access W_OK），无权限时给出
  明确错误而非依赖临时文件创建失败。
- 生效校验最低位移、磁盘余量等魔法数字收敛为命名常量。
- 旧 spec（v7/v7.1/v7.2）文件头加注"仅供对照，禁止用于当前代码"；
  新增 v7.3 打包配置。
- 新增测试 13 项（总 68）：单页连续堆栈读写、陈旧 meta 拒绝、位移表
  插值标记、FLANN 路径平移恢复、插值间隙拒绝、报告版本/溯源/列序、
  CSV 转义、批处理进度单调、内存探测、界面两段式加载与内存确认、
  预览平移钳制、配置往返。

## 7.2.0 - 2026-09-07

### 默认参数与 ImageJ 对齐

- 检测与匹配默认值对齐 Fiji "Linear Stack Alignment with SIFT"：
  closest/next closest ratio 0.75→0.92，RANSAC 对齐误差 3→25 px，
  最小内点比例 0.10→0.05；initial sigma 1.6 与 steps/octave 3 原已一致。
- 本工具特有的质量门控默认放宽到与 ImageJ 相当的非约束水平：
  最少匹配点/最少内点降至下限 3，最大残差=25 px（等于 RANSAC 阈值），
  有效帧对比例 0.05，最大插值间隙 10000。失败帧对仍按相邻可靠速度
  插值并在审计报告中警告——ImageJ 是静默沿用上一帧模型（等效零校正），
  本工具不会静默填零。
- 保留的刻意差异：特征点数默认上限 5000（ImageJ 无上限；设 0 可取消，
  大堆栈慎用）、OpenCV 特有的对比度/边缘阈值、纯平移模型（不含 ImageJ
  默认 Rigid 的旋转分量）。
- 已知行为变化：对称双峰/冲突簇拒绝依赖紧 RANSAC 阈值，默认 25 px 下
  RANSAC 会合并冲突簇（与 ImageJ 宽容行为一致）；需要该保护时把
  RANSAC px 调回 3。相关机制测试改为显式注入紧阈值继续覆盖，
  新增默认值对齐回归测试。
- GUI 参数区标题更名，注明"检测与匹配默认一致"；点"默认"按钮即恢复
  ImageJ 对齐参数。
- 新增独立打包配置 `TIFF漂移矫正工具v7.2.spec`（产物 `v7.2.exe`）；
  v7.1 spec 保留供对照。

## 7.1.1 - 2026-09-07

### 批处理轴确认

- 修复 v7.1.0 批处理对 C/Z 轴文件"只拒不放"的流程死胡同：错误提示引导
  设置 `allow_ambiguous_axes=True`，但 GUI 没有该入口，TEM 相机输出的
  时间轴被标为 slices/Z 的堆栈完全无法批量处理。
- 批处理启动前对含 C/Z 轴的文件统一询问一次（只读元数据预扫描）：确认后
  按页顺序作为时间帧处理；拒绝则仅跳过这些文件并在报告中记录，其余照常。
- 重写拒绝时的错误文案，指向批处理确认对话框而不是内部参数。
- 新增批处理确认流的 GUI 回归测试。

## 7.1.0 - 2026-09-06

### 多维序列防线（P0）

- 修复 ImageJ hyperstack（如 TCYX/TZYX）被静默当作时间帧的缺陷：序列轴只要
  包含通道（C）或层（Z）维度，无论是否同时存在 T 轴，一律要求人工确认。
  实测 TCYX 4 通道文件此前会产生零警告并被当作 3 倍数量的时间帧矫正。
- `inspect_stack` 返回值新增 `confirm_required`（阻断级）与 `warnings`
  （建议级）两级；ImageJ 元数据的 channels/slices/frames 会写入确认文案。
- 批处理无人值守，默认拒绝轴含 C/Z 的文件；确认数据无误后可用
  `allow_ambiguous_axes=True` 显式放行。

### 界面与流程健壮性（P1/P2）

- UI 事件泵加固：后台回调的异常只记录日志不再传播，事件泵始终重排自身；
  此前一次未预期异常会让所有后续任务完成/进度/错误回调永久失联。
- 批处理保存前预检同名输出并询问是否覆盖；输出目录与输入目录相同时明确
  提示二次矫正风险。
- 强制退出窗口后直接结束进程，不再被非 daemon 后台线程悬挂。

### 审计与显示改进（P2）

- 审计报告时间戳精确到微秒，同秒内连续两次批处理不再互相覆盖；报告新增
  `settings`（检测参数/跳帧/裁剪模式/覆盖选项），取消时在途文件以
  `cancelled` 状态入档。
- `correct_and_save` 新增可选 `verify_info` 出参，回填裁剪区域与防空转校验
  的变化像素比例；裁剪后同步更新 meta 的 `shape`。
- 预览显示范围改用与检测一致的 P1--P99.5 稳健百分位：uint16 数据存在少量
  热像素时预览不再整体发黑。
- 单帧堆栈拖动帧滑条、未加载文件时开启标记模式点击预览，均不再崩溃。

### 代码质量（P2）

- SIFT 参数范围校验收敛到核心层 `validate_sift_params`，GUI 只负责解析；
  修复 GUI 放过 ratio<0.1 而核心报错的不一致，未知参数键一律报错。
- 跳帧间隔为非正数时显式报错，不再静默钳制为 1。
- 移除 pyproject 中 unittest 不读取的无效 `[tool.unittest]` 配置段。

## 7.0.3 - 2026-08-30

### 真实数据矫正修复

- 移除 v7 错误引入的可靠帧对速度 MAD 清洗。TEM 堆栈中的真实阶跃和非匀速漂移
  已通过 RANSAC 与残差门控，不得再次被全局统计改写；仅对质量门控失败的帧对插值。
- 使用 `Substack (1-500).tif` 实测：同为 499/499 可靠帧对，最大累计漂移从
  错误的 1.34 px 恢复为 193.38 px，与 v5.2 一致；保存后再检测的最大残余漂移
  为 0.269 px，改善约 720 倍。
- “尚未检测”改用 `None` 表示，修复批处理把加载时的全零数组当成已检测结果复用、
  从而原样保存 `_corrected.tif` 的问题。
- 手动模式只有在实际调整过位移后才能绕过自动检测保存；批处理只复用具有
  `DetectionResult` 的当前文件。
- 保存时对最大位移帧执行像素级生效校验：明显非零位移若没有改变任何像素，
  则原子写入失败并保留既有输出，不再假报成功。
- 新增真实非匀速累计、零位移缓存、未检测保存和矫正空转的回归测试。

## 7.0.1 - 2026-08-29

### 矫正回归修复

- 恢复 v5.2 的 RANSAC 空间一致性内点筛选；最终漂移仍取内点位移中位数，
  因此矫正只应用平移，不应用仿射模型中的旋转或缩放。
- 修复 v7 纯中位数门控在跳帧和较大帧间位移时大量拒绝真实匹配的问题。
  在 v5.2 自带的 236 帧 `test.tif`、跳帧 4 条件下，可靠帧对由 2/59 恢复到 52/59。
- 增加冲突双峰拒绝，防止 RANSAC 在规模相同、方向相反的两个匹配簇中武断选边。
- 新增检测、反向平移、裁剪、TIFF 写出和回读的端到端回归测试。

### 大文件与构建

- 取消默认 3 GiB 堆栈总大小限制；超大文件改由实际可用内存决定。
- 构建流程改为隔离环境，并排除非运行时的 `pkg_resources/jaraco` 工具链。

## 7.0.0 - 2026-07-31

### 合并

- 以 v5.2 安全版为基础，合并 v6.1 算法改进，版本迭代至 v7。
- v5.2 与 v6 源码目录已归档至 `<仓库根>\08-历史版本`。

### 保留自 v5.2（安全框架）

- 所有 TIFF 输出临时文件写入、验证后原子替换；失败和取消不删除既有目标文件。
- 默认输出 `_corrected.tif`，禁止覆盖输入，已有输出需明确确认。
- tifffile 逐页校验；拒绝混合尺寸、混合类型、多 series 和非二维灰度页；
  支持 uint8/16、int16/32、uint32、float32/64，1-bit 转 uint8。
- 单 `TiffWriter` 输出、BigTIFF 自动启用、输出回读验证、磁盘空间预检。
- 全局稳健归一化（P1--P99.5）、显式失败语义、每帧对质量与残差记录。
- 默认裁剪至共同有效区域；GUI 后台加载/处理、文件身份绑定、安全退出、
  有限值输入校验和批量 JSON/CSV 审计报告。

### 合并自 v6.1（算法与代码）

- 配准改为纯平移鲁棒中位数估计：不再用 RANSAC 仿射模型挑选内点，
  避免缩放/旋转内点混入平移统计。
- `_match_pair` 的 MAD 门控在 mad=0 退化时仅按注册阈值门控，
  避免对称双峰匹配簇拉宽门控导致系统偏差。
- 跳帧匹配先换算成每帧速度再 MAD 清洗，修复末段跨度较短时被误判的问题。
- 漂移检测二维帧校验改为按关键帧惰性验证，报错给出帧序号与形状。
- `DriftCorrector` 增加 `border_value`，与 `border_mode` 一起供定量管线选用；
  新增 `correct_frames_list` 保持 v6 API。
- `nfeatures` 默认统一为 5000；GUI 无遗留死代码。

### v7 细化

- 速度清洗仅在有效速度样本 >= 5 时启用：短序列中 MAD 不可靠，
  避免把正常加速度（约 0.2--0.3 px/帧）误判为异常。
- 清洗产生的异常速度帧对会单独计入 `DetectionResult.warnings`。
- 新增 `DriftResult = DetectionResult` 兼容别名（保留 v5.2 属性访问契约）。
- 新增回归测试：MAD=0 对称双峰显式失败、纯平移鲁棒中位数、
  速度清洗与短序列保护、`border_value`、`correct_frames_list`。
