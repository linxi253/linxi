# 更新记录

## v1.2.0 — 2026-09-28

- 预览帧的读取与降采样移入后台线程：超大帧（如 20000×20000）加载不再冻结界面；
  切帧/切文件期间保留旧图，过期加载结果自动丢弃。
- 新增"载入参数清单"：可从任意 `.filter.json` 恢复全部滤镜参数，补全
  "保存清单 → 复现处理"的闭环；无效清单（未知参数/越界/结构错误）会被拒绝
  且不改动当前参数。
- 参数清单升级为 schema v2：新增源文件 SHA-256（可验证源未被替换）、
  处理时长、输出大小，以及 `skipped_tag_codes`（未复制进输出的标签明细，
  不再需要使用者对两个码表做集合差）。
- 批处理结构检查阶段显示 i/N 进度；帧级进度按时间节流，百万帧堆栈不再
  淹没事件队列；批处理失败明细追加写入输出目录的
  `TIF_FilterTool-errors.log`。
- 灰度文件加载后自动禁用色彩类滑块（白平衡/色温/色调/自然饱和度/饱和度），
  避免无效调节；RGB 文件恢复可用。
- 键盘快捷键：←/→ 切换帧、PgUp/PgDn 切换文件、Ctrl+O 打开文件、
  Ctrl+Shift+O 打开文件夹、Ctrl+S 处理保存。
- 打开文件夹的权限/IO 异常不再裸露为 Tk 回调错误；输出目录选择时即探测
  写权限（含网络共享/只读盘），批处理启动前再次校验。
- 单帧内存峰值估算：超过 4 GB 的图像在加载时给出提示。
- 画布重绘 30ms 防抖，拖动窗口不再逐像素全图重采样。
- 滤镜系数全部提升为命名常量（`image_filters.py` 顶部集中管理），数值
  行为与 v1.1.0 完全一致。
- 打包：UPX 关闭（杀软误报/原生 DLL 损坏风险）；依赖统一加上界；
  新增 `conftest.py`，pytest 可直接收集运行全部测试（无显示环境自动跳过
  GUI 用例）。

## v1.1.0 — 2026-09-08

- 新增 TIFF 多文件选择、帧号跳转和可直接取消的批处理进度区。
- 当前堆栈的保存入口明确处理全部帧；批处理入口对整个文件列表应用同一组滤镜参数，每个输入对应一个完整 TIFF。
- 进度显示当前文件序号、当前帧和总帧数；成功后汇总实际保存的帧数。
- 修复 ImageJ 二进制 IJMetadata 被解析成字典后无法写出的错误，重新编码 Info、Labels、Ranges、LUTs 等信息并保留字节序。
- 批量处理重名文件时重新分配输出名；已有参数清单也参与避让，避免覆盖或使后续任务失败。
- 统一 GUI 标题、参数清单、EXE 文件属性的版本号；构建生成带版本文件名和 SHA-256 校验和。
- 增加 7 项堆栈与 GUI 回归测试，以及可重复运行的真实样例全栈验收脚本。
