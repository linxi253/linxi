# 更新日志

## v1.1.0

第二轮代码审查后的修复版。重点：预览/写盘的数值保真、GUI 状态一致性
（不再有静默丢工作的路径）、大图内存减半。所有修复均带回归测试。

### 修复

- **P0 预览降采样的假摩尔纹**：`_disp` 原先用 `arr[::step]` 裸抽样，高于新
  Nyquist（0.5/step）的分量折叠回来，大图（step≥2）上细晶格在预览里呈现为
  假摩尔纹——用户据此刻画的 ROI 会跟着错。改为均值池化
  （`deloc_core.downsample_mean()`，step×step 块面积平均）；只影响显示，
  结果计算仍在全分辨率图上。
- **P1 整数位深写出偏低约半个灰阶**：`astype` 是向零截断，100.7 存成 100。
  改为 `np.rint` 四舍五入后再裁剪。对「便于后续定量」的输出不可忽略。
- **P1 写盘非原子**：磁盘满 / 进程中途被杀会留下半个 TIFF 被当成有效结果。
  改为同目录临时文件 + `os.replace` 原子替换，失败时清理临时文件。
- **P1 打开文件的状态撕裂**：`open_file` 原先在帧号对话框弹出前就写入
  `_path`——取消后 `_path` 指向新文件、`img` 还是旧图，保存时的防覆盖
  guard 与默认输出文件名张冠李戴。现在取消时不动任何状态；载入失败回滚
  `_path` / `_frame`。
- **P1 翻帧/关闭静默丢工作**：有 ROI 时翻帧（`←`/`→`）先确认，关闭窗口前
  有未保存 ROI 先确认；销毁前取消未触发的防抖 `after` 任务。
- **P2 ROI 坐标拒绝 NaN/Inf**：Python 的 json 会原样解析 NaN 字面量，NaN
  坐标会让 PIL 栅格化行为未定义。损坏条目仍跳过（不让整个文件读失败），
  但 `RoiSet.skipped_on_load` 计数并在状态栏告知用户跳了几个。
- **P2 `band_feather` 不随 ROI JSON 往返**：换图复现时 FFT 参数缺一角；
  且 `load_roi` 不经过 `apply_band`，engine 里的副本还是旧值，render 会用
  旧羽化算 FFT。现在写盘/回读/同步三处补齐。
- **P2 validate 脚本曾内置某个人的本机默认路径**：隐私信息
  进了仓库且不可移植。现在没有内置默认路径，真实数据一律 `--input` 传入；
  `mask_to_polygon` 缺 scikit-image 时给出清晰的安装指引（该依赖已列入
  `requirements-dev.txt`，程序本体不依赖）。

### 变更

- FFT 改用 `scipy.fft`：float32 输入保持 complex64（`np.fft` 一律升
  complex128），4096² 图谱内存峰值减半。数值输出变化在 1e-5 量级，
  不变量测试（1e-3 门槛）不受影响。
- `radial_frequency` 改广播实现：`np.mgrid` 会物化两个 int64 全尺寸数组
  （4096² 约 268MB），结果本身只是 float32。
- `CleanEngine` 缓存键从 `id(img)` 改为持有引用后的身份比较：id 会被
  CPython 回收复用，换图后可能静默命中上一张图的缓存分量。
- `_recompute(full)` 的两个分支数学上完全等价（`rasterize` 内部本就先查
  距离场缓存），删掉误导维护者的伪分支。
- 光标坐标移到状态栏独立分栏：原先每次鼠标移动都覆盖主状态栏，
  「自动选带 / 已保存 / 频带无效」这类提示一闪而过。
- `main()` 声明 Windows DPI 感知：显示缩放（如 150%）下界面不再发虚。

### 校验

- 107 个测试（核心算法 31 / ROI 模型 32 / TIF 读写 28 / GUI 回归 16，
  无显示环境自动跳过）。

## v1.0.1

代码审查后的修复版。**行为有两处变化**：选带的频率语义（修 bug）与导出文件的
位深/元数据（修 bug）。已在立项尺寸数据（726×478，晶格 13.6 px）上端到端复验。

### 修复

- **P0 频谱/自动选带的频率单位错了 step 倍**（影响所有长边 > 512 px 的图，也就是
  几乎全部真实数据）。原先先把图隔点降到 512 再算谱，频率轴被压缩 step 倍：
  在 726×478 的立项数据上 step=2，「点频谱选带」填进去的是 0.0943~0.1958，
  而正确值是 0.0478~0.0993 —— 虚影基本没被压掉（晶体外晶格残余 RMS 15.5）。
  现在频谱与自动选带一律在全分辨率图上计算，显示用的降采样只作用于谱图数组
  （块最大值），坐标恒为原图 cyc/px。修复后残余 RMS 降到 0.39。
  顺带把这段逻辑从 GUI 下沉到 `deloc_core.spectrum_overview()`，并补了回归测试。
- **P1 导出丢失标定元数据**：源的 ImageDescription（ImageJ `unit`/`spacing`）与
  XResolution / ResolutionUnit 全部没写进结果，处理后的图在 Fiji 里量晶格间距
  会得到错的物理尺度。现在这些字段随结果一起写回。
- **P1 浮点源被静默降位深**：float32/int32 源选「保持原位深」时会被降成
  uint8/uint16 并大面积裁剪。现在浮点源保持 float32，int8/int32 也纳入位深表。
- **P1 输入框里的按键会触发全局快捷键**：ttk.Entry 的 bindtags 含 toplevel，
  方向键在 Entry 类绑定里也不 break，所以在「下限/上限」输入框里按 ←/→ 会同时
  切帧，而切帧会重建 RoiSet —— 用户画好的 ROI 和撤销历史无提示地全部丢失。
  现在输入框有焦点时全局快捷键一律让路。
- **P1 只有「挖除区」时会把整幅图的晶格删掉**：掩膜必然全 0，保存时不再放行，
  并给出明确提示。
- **P1 裁剪提示时序**：原先先写盘再告知「有 x% 像素被裁剪」，用户只能重来；
  现在写盘前先算出比例并询问是否改存 float32。
- 载入 ROI 时校验 JSON 里的参数字段，坏值只在状态栏提示，不再抛未捕获异常
  （打包成 console=False 的 exe 后，那会表现为「点了没反应」）。
- `make_output_path(suffix="")` 不再返回源文件本身；写出前拒绝空图与含 NaN/Inf
  的数据（NaN 裁到整数位深会静默变成 0）。

### 变更

- `main()` 安装 `report_callback_exception`：Tk 回调里的异常改为落盘日志 + 弹窗，
  不再在无 stderr 的 exe 里无声消失。
- 依赖锁定：新增 `requirements.lock.txt` / `requirements-dev.lock.txt`（由
  `requirements*.txt` 在干净 venv 中解析生成，逐包精确版本）。
- `requirements*.txt` 改为 UTF-8 带 BOM：pip 用系统 locale 编码读 requirements
  文件，中文 Windows 是 GBK，没有 BOM 会直接 `UnicodeDecodeError` 装不上。
- 构建版本隔离：`build.bat` 自建并使用 `.venv-build`，不再用 PATH 上的 `python`
  装依赖；按 lock 安装并校验依赖可导入后才打包。

### 校验

- 90 个测试（核心算法 25 / ROI 模型 29 / TIF 读写 26 / GUI 回归 10，无显示环境
  自动跳过）；测试 fixture 显式声明 `photometric`，不再受 tifffile 默认值变化影响。

## v1.0.0

首个版本。从项目里的一次性脚本 `deloc_clean.py` 升级成带交互 ROI 的工具。

### 新增

- **手绘 ROI**：多边形 / 自由手绘 / 矩形 / 椭圆，支持加-减模式和撤销重做。
  取代原先基于低频阈值的自动掩膜，修掉"全帧里把其它真实晶体当晶体外删掉"的缺陷。
- **软掩膜**：由 ROI 生成有符号距离场，向外膨胀 + logistic 羽化，
  避免硬边接缝。膨胀/羽化滑块可实时预览（距离场带缓存）。
- **FFT 选带辅助**：频谱图可直接点峰填 `fmin/fmax`，另有径向功率谱和自动选带。
- **三态预览**：原图 / 结果 / 掩膜，同一灰阶。
- **导出**：处理结果 TIF（默认保位深，可选 float32，含裁剪统计）、
  三栏对比图 PNG、掩膜 PNG、ROI + 参数 JSON（可复用）。
- 多页栈取指定帧处理（`←` `→` 翻帧）。

### 算法

- 频带分离 + 掩膜加权：`out = base + (1 - strength*(1 - M)) * lat`
- 不变量在单元测试里逐条验证：掩膜全 1 恒等、强度 0 恒等、
  掩膜全 0 时等于 `base`、`lat` 均值为 0。
- 与立项脚本 `deloc_clean.py` 数值一致，差异仅来自边缘过渡形状。

### 已知限制

- 只处理单张图，堆栈批量套用未实现。
- 虚影与真晶格共享频带，只能靠空间位置分离；若虚影本身是真实结构，
  会连同真信号一起被抑制。

### 校验

- 65 个单元测试（核心算法 21 / ROI 模型 28 / TIF 读写 16）
- `validate_real_data.py`：真实液相 Ag 数据端到端 + 不变量检查
