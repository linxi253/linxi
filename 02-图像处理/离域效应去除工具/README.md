# 离域效应去除工具 v1.1.0

液相 HRTEM 照片里，晶体边界往外常拖出一条**白色条纹虚影**——那是晶格条纹经
CTF 离域（delocalization）后扩散到晶体外的分量。本工具让你**手绘圈出晶体真实
边界**，然后把晶体外那圈虚影抑制掉，同时**完整保留晶体内部的原子晶格**。

面向单张 TIF 的交互式处理。

---

## 直接运行

```text
dist/DelocCleaner.exe
```

## 从源码运行

需要 Python 3.9 及以上（开发环境实测 3.10）。

```powershell
python -X utf8 -m pip install -r requirements.lock.txt
python .\main.py
```

- `-X utf8` 建议保留：pip 读 requirements 文件时用系统 locale 编码，中文 Windows
  是 GBK，遇到 UTF-8 中文注释会直接报 `UnicodeDecodeError`。requirements 文件已带
  UTF-8 BOM 兜底，但显式加 `-X utf8` 更稳。
- `requirements.txt` / `requirements-dev.txt` 是可读的版本范围；
  `requirements.lock.txt` / `requirements-dev.lock.txt` 是自动生成、逐包精确锁定的
  版本（由前两者在干净 venv 中解析而来）。要复现已验证的环境，请用 lock 文件。

## 为什么需要"手绘"而不是自动识别

虚影和真晶格**共享同一段空间频率**，所以频率滤波分不开：按频率把这段砍掉，
晶体内部的晶格也会一起没。唯一能把两者分开的是**空间位置**。

自动阈值法（"暗的算晶体"）在单颗粒裁剪图上能凑合用，但换到全帧就失效——
全帧里还有好几块真实晶体，自动掩膜会把它们当成"晶体外"把晶格删掉。

所以这里把手选权交给你。

## 使用流程

1. **打开 TIF**（`打开 TIF…`）。多页栈会弹窗问你要处理第几帧。
2. **定频带**。右侧「晶格频带」面板上直接**点频谱图上的晶格峰**，上下限会自动
   填好；也可以点「自动选带」，或手工输入。径向功率谱上那两条绿虚线就是当前
   选中的带。频率一律是**原图像素**坐标系的 cycles/pixel，与「晶格下限/上限」
   输入框同一套单位，面板读数可以直接抄进去。
3. **画 ROI**。在画布上圈出**晶体真实边界**（不是虚影带的外沿）：
   - `多边形` —— 逐点点击，**双击**结束
   - `手绘` —— 按住拖一圈
   - `矩形` / `椭圆` —— 拖一下
   - 勾 `挖除(减)` 可以挖掉不要的区域（比如颗粒内部的孔洞）
   - 多块晶体就画多个
4. **调掩膜**。「向外膨胀」把它往外扩出去盖住虚影带，「边缘羽化」控制过渡柔和度。
   预览切到 `掩膜` 能看到覆盖范围对不对（亮 = 保留晶格）。
5. **定强度**。`1.0` 完全移除虚影；`0.7` 只衰减到 30%，更保守。
6. **保存结果**，或存一张三栏对比图。ROI 可以存成 JSON，换帧时直接载入。

### 画布操作

| 操作 | 效果 |
|---|---|
| 左键 | 画 ROI |
| 中键拖动 / `Ctrl` + 左键拖动 | 平移 |
| 滚轮 | 缩放 |
| `Enter` | 结束当前多边形 |
| `Esc` | 放弃当前未完成的形状 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `←` `→` | 多页栈切换帧 |

> 焦点在「下限/上限」输入框里时，上表的快捷键一律让路，方向键只移动光标——
> 否则在输入框里按 ←/→ 会顺手切帧并把 ROI 清掉。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 晶格下限 / 上限 | 0.0580 / 0.0920 | 单位是 cycles/pixel（原图像素）。立项的 Ag 液相数据晶格周期约 13.6 px，对应这一段 |
| 带宽羽化 | 2.0 | 频带边缘软化，抑制截断振铃 |
| 向外膨胀 | 6 px | 把保留区往外推，用来盖住晶体外的虚影带 |
| 边缘羽化 | 8 px | 过渡柔和度；太小会出现硬边接缝 |
| 抑制强度 | 1.0 | `1.0` 完全移除，`0.7` 只衰减 |

**换数据集时频带一定要重选**，不要照抄默认值。

## 算法

```text
1) FFT 拆图:   base + lat = img
               lat  是晶格带分量（默认 0.058–0.092 cyc/px）
               base 是剩下的一切（低频形貌 + 高频噪声）
2) ROI -> 软掩膜 M     手绘多边形 -> 有符号距离场 -> 向外膨胀 + logistic 羽化
3) 输出 = base + (1 - strength * (1 - M)) * lat

   M = 1（晶体内部） -> gain = 1    晶格原样保留
   M = 0（晶体外部） -> gain = 1 - strength
```

不变量（单元测试里逐条验证）：

- 掩膜全 1 → 输出恒等于原图
- 掩膜全 0 且强度 0 → 输出恒等于原图
- 掩膜全 0 且强度 1 → 输出恒等于 `base`
- 晶格带分量 `lat` 的均值为 0

实现细节：**有符号距离场只依赖 ROI 形状**，与膨胀/羽化无关，所以缓存下来
——拖动这两个滑块时不必重算距离变换，预览才能跟手。同样地，FFT 只在频带
变化时重算，掩膜和强度变化只走一次逐像素乘加。

频谱面板与「自动选带」一律在**全分辨率**图上计算：先隔点降采样再算谱会把频率轴
压缩 step 倍并引入混叠，导致选到错误的频带（详见 CHANGELOG v1.0.1）。显示用的
降采样只作用在谱图数组上，坐标始终是原图 cyc/px。

## 输入与输出

- **输入**：`.tif/.tiff`。支持灰度、RGB/RGBA、8/16/32 位、多页堆栈（取指定帧）。
- **输出**：默认保持原位深（源是 8bit 就出 8bit，源是浮点就出 float32）；也可强制
  `float32`。**写盘前**会先算出会超出量程的像素比例，不为 0 就先问你要不要改存
  float32，而不是写完再告知。
- **标定元数据随结果一起保留**：XResolution / ResolutionUnit 以及 ImageJ 描述里的
  `unit` / `spacing` 等字段都会写回输出文件，处理后的图在 Fiji/ImageJ 里量出来的
  物理尺度与源图一致。
- **绝不覆盖源文件**：输出路径会在文件名后加 `_deloc` 等后缀自动避让。
- 附加产物：三栏对比图 PNG（原图 / 结果 / 掩膜，**同一灰阶**）、掩膜 PNG、
  ROI + 参数 JSON。

## 限制

- **一次只处理一张图（一帧）**。堆栈批量套用尚未实现。
- **全帧多晶体要分别画 ROI**。掩膜是"保留区"，没圈到的地方一律按晶体外处理。
- **至少要有一块「保留区」**。只画「挖除区」时掩膜全为 0、整幅图的晶格都会被移除，
  保存时会被拦住并提示。
- 算法**只压制指定频带的分量**，不改变形状、亮度、对比度。所以如果虚影的能量
  落在所选频带之外，它只会被部分削弱——这时应当调整频带，而不是加大强度。
- 若虚影其实是**真实结构**（比如薄的 Ag 片层、莫尔条纹），本工具会把真信号一起
  删掉。上机前先用「掩膜」预览和「原图 / 结果」对比确认。

## 测试与校验

```powershell
python -m pytest tests -q              # 107 个测试（含 GUI 层回归，无显示环境自动跳过）
python .\validate_real_data.py         # 不带参数 = 合成数据自检 + 不变量检查
```

`validate_real_data.py` 没有内置的默认数据路径；走真实数据时通过 `--input`
指定图像，那条路径额外需要 `scikit-image`（只用于轮廓提取）：
`python -X utf8 -m pip install scikit-image`。
退出码：`0` = 真实数据校验全部通过；`3` = 仅合成自检通过（只证明算法
不变量，不代表真实数据处理正确）；`1` = 有不变量未通过。CI/批处理
不要把 3 当成真实验证的通过。
也可以指定参考结果与频带：

```powershell
python .\validate_real_data.py --input 某图.tif --fmin 0.06 --fmax 0.09
```

## 打包

```powershell
.\build.bat
```

流程：在**自带隔离 venv**（`.venv-build`，缺失时自动创建）里按
`requirements-dev.lock.txt` 安装精确锁定的依赖 → 校验依赖可导入 → 跑测试 →
PyInstaller 打包，产物为 `dist\DelocCleaner.exe`。

构建脚本不再用 PATH 上的 `python` 装依赖，因此同一份源码在任何机器上都会用同一套
依赖版本；若 venv 的 Python 版本与 lock 解析时用的版本（3.10）不同，脚本会给出警告。
`hook-imagecodecs.py` 负责把 imagecodecs 的 TIFF 编解码扩展按需收进包内
（它用 `__getattr__` 惰性加载，静态分析看不到）。
